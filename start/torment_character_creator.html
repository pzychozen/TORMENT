05 — features
Character System
Living identity layer — seed planting, drift protection, gravity correction. This is what makes your character stay themselves over time. Recommended ON.
Memory Compression
Event-gated compression with deep memory store. Old memories get compressed and can "spirit return" as echoes later. Turn on after your character has 100+ conversation turns. Off by default.
crystal attunement (shared — applies to solo and hivemind)
Symbolic Resonant Geometry is a kernel-level feature. Its settings affect memory dynamics for solo characters and hivemind agents alike — toggle the master switch below to enable it, then configure the attunement details.
Crystal Attunement (SRG)
Living memory dynamics powered by Symbolic Resonant Geometry. Each memory gets a heartbeat (Class A: slow/deep or Class B: fast/active), a golden tower frequency band, and a breathing compression field. Identity memories become indestructible crystals. Memories that overlap semantically collide — rhythm syncs, amplitude preserves identity. Optional — everything works without it.
Attune your character to the golden frequency tower. These settings control how SRG assigns frequency bands and heartbeat classes to the memories it produces.
If your character has distinct identity modes (like Ryuki's playful / protector / self), map each mode to a golden tower band. Leave empty for automatic band assignment based on memory coherence.
Crystal Protection
Identity memories stay indestructible. Non-identity memories can be compressed. Recommended ON when SRG is enabled.
advanced cognition (optional)
Optional runtime capabilities that control how this character thinks, remembers, and participates in the TORMENT system. These are execution-layer features — not personality traits. Leave everything off for standard operation.
Spine-Governed Execution
Use governed action routing and trust-aware execution paths. All cognition requests pass through the Spine authority layer.
Thinking-Layer Assist
Use the advisory thinking controller for task framing, memory planning, and action hints. Runs as a non-authoritative sidecar — observes but never overrides.
Identity-Sensitive Cognition
Protect character continuity and prioritize drift-sensitive responses. The thinking layer will escalate identity-adjacent inputs to governed review.
Collective / Hive Participation
Allow this character to participate in collective field and hive-style cognition paths, including echo re-ingestion and convergence detection.
SRG-Aware State Handling
Expose SRG-linked state and resonance-aware runtime behavior. The thinking layer will incorporate crystal frequency and heartbeat class into memory planning.
Archive / Deep-Memory Recall
Allow archive and deep-memory lanes to participate in recall. Enables the thinking layer to route queries through compressed and spirit-returned memory stores.
Live-Social Compact Mode
Enable compact response mode for live conversational contexts (voice, spaces, audio). Reduces token budget and depth for faster, shorter replies.
stance and participation
When Contextual Abstention is enabled, the stance policy decides when the character responds, defers, asks for clarification, or stays silent. If the kernel provides geometric state, stance thresholds are nudged by ±15% based on coherence, stability, and social resonance — but behavior remains deterministic without it. Three levels: stance off (always respond), stance on without geometry (rule-based), stance on with geometry (kernel-modulated rules).
Contextual Abstention
Allows the character to decline, defer, remain silent, or wait for a better context before responding. Enables alive-feeling behavior where the character chooses when and how to participate rather than always answering directly.

06 — embeddings
Embeddings are how TORMENT understands what memories mean — it converts text into numbers so it can find related memories when your character needs them. Better embeddings = better memory retrieval.
Hash (Testing)
Zero dependencies. No real understanding of meaning — just pattern matching. Use for quick testing only.
Sentence-Transformers
Real semantic understanding. Recommended for production. Requires: pip install sentence-transformers
If your LLM is also running on GPU (e.g. Ollama local), embedding + LLM will compete for VRAM. CPU is safer for embeddings — they're fast enough on CPU and won't starve your model.
Ollama Embeddings
Use Ollama's built-in embedding models. Good if you already run Ollama.
