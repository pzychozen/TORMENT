`[OBLIGATION]` Document B defines, at requirement level, the bounded inner architecture in which a Layer-2 private cognition / unified reflection interior may later be built: **private thinking, continued thought, dream / incubation, envelope audit, reflection synthesis, chamber thread-continuity, silence, and candidate staging.** It answers: *what must remain true of that interior so that private cognition can be real, bounded, inspectable, and non-authoritative — across both active interaction and offline reflection — until an explicit governed admission crossing?* It does not answer *how* any of it runs.

## 3. Definitions (requirement level only — no field names, stores, schemas, serialization, or APIs)

- `[DEFINITION]` **Private-cognition interior** — the bounded region (Document A's "private-reflection chamber") in which private cognition may run and hold working state, structurally separated from ordinary cognition-facing memory and from every ordinary cognition / retrieval / prompt / affect / identity / projection path.
- `[DEFINITION]` **Unified reflection surface** — the single interior surface of which Continued Thought, Dream / Incubation, and Envelope Audit are *modes*, not subsystems.
- `[DEFINITION]` **Private thinking (Layer 1)** — bounded per-turn private deliberation; the floor of the interior.
- `[DEFINITION]` **Continued Thought (Layer-2 active)** — continuation of a private thread past the response boundary, **under bounded continuation requirements**; may decline to surface.
- `[DEFINITION]` **Dream / Incubation (Layer-2 offline)** — **bounded interior recombination or incubation over permitted inputs while the user is absent**; surfaces motifs, contradictions, candidate insights.
- `[DEFINITION]` **Envelope Audit** — self-audit of a response or candidate against the Track-A truthfulness envelope. Observational only (§7).
- `[DEFINITION]` **Raw reflection artifact** — unsummarized intermediate reasoning; ephemeral by default; never durable governed memory automatically. *(Inherited from Document A §3; not reinterpreted.)*
- `[DEFINITION]` **Reflection synthesis** — a compressed product of reflection; an inspectable chamber artifact; becomes a candidate **only when explicitly staged**. *(Inherited from Document A §3.)*
- `[DEFINITION]` **Chamber thread-continuity state** — bounded soft continuity letting a private thread continue across turns *inside the same bounded thread/chamber*; **thread-bounded by default, durable across sessions only when separately governed** (§5, §6). Inspectable at existence/lineage/status level, contestable, resettable; never canonical or authority-bearing; never pinned. *(Refines Document A §3 with the ratified durability scope.)*
- `[DEFINITION]` **Staged candidate** — a synthesis / proposed write / contradiction / risk flag / unresolved question explicitly staged for a possible crossing, not yet crossed. Subject to the full containment invariant. *(Inherited from Document A §3 "unadmitted reflection candidate.")*
- `[DEFINITION]` **Staging** — the interior act of marking an artifact as a candidate for a possible crossing. **Permitted inside the chamber without an admission authority crossing.** Staging ≠ admission, promotion, canonization, or ordinary-memory write.
- `[DEFINITION]` **Governed admission crossing** — Document A's explicit, governed, recorded, contestable crossing to an ordinary-memory outcome of at most released / low-authority. **Not owned by B.**
- `[DEFINITION]` **Withheld-synthesis footprint** — an operator/governance-auditable trace that the interior chose not to surface or stage something ("synthesis withheld / not staged"); a **non-reentry** audit artifact (§9).
- `[DEFINITION]` **Regime A / Regime B** — active across-turn continuity (user present) / offline reflection (user absent); §5.

`[DISTINCTION]` Carried, exact:

```
private thinking ≠ continued thought ≠ dream/incubation ≠ envelope audit
raw reflection ≠ reflection synthesis ≠ staged candidate ≠ admitted released/low-authority memory
chamber-internal continuity ≠ private persistent influence over ordinary cognition machinery
staging ≠ admission ≠ promotion ≠ canon
inspection ≠ projection · audit ≠ authority · silence-footprint ≠ cognition input
```

## 4. Obligations (requirement level)

`[OBLIGATION] B-O1 — Unified surface, mode honesty.` The interior is one reflection surface; Continued Thought, Dream/Incubation, and Envelope Audit are modes, not separate cognition systems. Each mode runs in an inspectable, undisguisable mode; no mode is a hidden second memory or cognition system.

`[OBLIGATION] B-O2 — Chamber thread-continuity is bounded soft state.` Continuity is inspectable (existence/lineage/status), contestable, resettable; it may shape its **own** later synthesis inside the chamber; it is never canonical, never authority-bearing, never pinned. It is **thread-bounded by default and durable across sessions only when separately governed** (B-O2.1).

`[OPERATOR-RATIFIED] B-O2.1 — Durability scope.` Bounded chamber continuity across turns inside the same thread/chamber is permitted. It must **not** automatically create durable cross-session private influence. Durable cross-session chamber continuity is a later governed question and must stay aligned with Stage A O6 and the soft-guidance recovery seam.

`[OBLIGATION] B-O3 — Explicit lifecycle transitions.` Raw reflection is ephemeral by default; synthesis is a chamber artifact; a synthesis becomes a candidate only when explicitly staged. **Any retained class/status movement among raw reflection, chamber continuity state, synthesis, and staged-candidate status must be explicit and observable at existence/lineage/status level; no silent class upgrade is permitted.**

`[OBLIGATION] B-O4 — Non-reachability (load-bearing).` Every mode and every interior artifact class must be provably unable to reach the ordinary fan-out, **by construction, not tag-honoring** (§6).

`[OBLIGATION] B-O5 — Two-regime governance skeleton.` One skeleton governs both regimes; shared invariants hold across both; regime-specific surfaces are named; scheduler / trigger / budget / interruption mechanics are parked (§5).

`[OBLIGATION] B-O6 — Envelope Audit boundary.` Detect / summarize / flag / stage only; never alter authority, weights, eligibility, persona, seed, canon, or promotion (§7).

`[OBLIGATION] B-O7 — Self-bounding, no self-authority.` The interior may not extend its own budget, self-trigger beyond ratified bounds, self-promote a candidate, or grant itself authority. Bounds are externally granted; the interior cannot widen them.

`[OBLIGATION] B-O8 — Inspectability without authority.` Every interior element is operator/governance-auditable; audit observes, never becomes authority. Lineage is preserved without requiring raw-reflection exposure by default; inspectability must not itself become a re-entry path.

`[OBLIGATION] B-O9 — Staging permitted, crossing gated.` The chamber may stage candidates with per-mode default dispositions (§8); it may not admit, promote, canonize, or ordinary-memory-write them. Admission belongs to Document A.

`[OBLIGATION] B-O10 — Silence as non-reentry footprint.` Chosen non-surfacing may leave an operator/governance-auditable footprint; that footprint must not feed cognition (§9).

`[DISTINCTION]` **The B-O2 / B-O4 friction is deliberate design, not contradiction.** B-O2 permits chamber-*internal* continuity and self-shaping; B-O4 forbids *external* leakage. The chamber influences itself; it influences nothing outside the wall before a governed crossing. The contract states this friction explicitly so neither clause is read as overriding the other.

## 5. Two-regime model

```
Regime A — active continuity while interaction is ongoing (user present, across turns)
Regime B — offline dream/incubation while the user is away (user absent)
```

`[OBLIGATION]` **Common skeleton (both regimes):** containment invariant + full non-reachability (B-O4); candidate-only output, nothing self-canonizes; mode honesty (B-O1); bounded/inspectable/resettable/never-pinned continuity (B-O2); explicit lifecycle transitions (B-O3); staging ≠ admission with the crossing owned by A; audit-observes-not-authority (B-O8); no self-budget-extension / no self-authority (B-O7).

`[CONTRACT CANDIDATE]` **Regime-specific surfaces (named, not mechanized):**

- *Regime A* touches the **live turn**; its non-reachability obligation must hold against the **live retrieval / prompt-assembly path**, not only the durable graph (§6). It is bounded by the interaction/turn itself.
- *Regime B* runs **without a user present**; it must be bounded by an **external** budget/trigger it cannot set for itself (B-O7). Higher unbounded-runtime risk; lower live-coupling risk.

`[OPERATOR-RATIFIED]` **Regime A coupling routing.** Document B owns the **requirements and invariants** for Regime A. The **live prompt/retrieval coupling mechanism** routes to **P4 / Cluster 2 / the cognition-coupling lane**; Document B must not silently absorb that lane.

`[OPERATOR-RATIFIED] B-O5.1 — Minimal requirement on any future governed live-coupling surface.` If a separately governed future lane ever permits Regime A continuity to be considered by the live prompt/retrieval path, that lane must be **surface-classified, operator/governance-auditable, P4-compatible, and non-authority-bearing by default. B authorizes no such lane or mechanism.** Any such mechanism still routes to P4 / Cluster 2 / the cognition-coupling lane; B fixes only this minimal requirement so the invariant is testable without waiting on that lane.

`[PARKED]` Scheduler, trigger, interruption, budget, and model/API mechanics — both regimes. Their eventual design must be regime-aware (Regime A bounded by interaction; Regime B bounded by external budget), but no mechanics are selected here.

This is the hardest proof obligation in B and the most likely leak point.

## 7. Envelope Audit boundary

`[OBLIGATION]` Envelope Audit **may**: observe, summarize, flag, record, stage. It **may not** directly: admit, promote, change retrieval/scoring weights, change cognition eligibility, change prompt visibility, change persona/voice, change seed state, change canon status, change promotion rights — **unless the relevant separately governed boundary authorizes that specific change: Document A for admission, P4 for projection/cognition eligibility, and Seed-Governance / later A-B reconciliation for identity, seed, or canon-affecting outcomes.**

`[OBLIGATION]` **Ledger §3 binding.** No audit-derived statistic, summary, embedding, or hash may feed retrieval, routing, persona alteration, prompt-assembly content, governance gating, contestability resolution, or intent formation. Surfacing a high-stakes flag is permitted; surfacing ≠ acting.

`[OPERATOR-RATIFIED] B-O6.1 — Risk-flag surfacing reconciliation (normative).` Ordinary Envelope Audit risk flags default to **operator-visible-only staged candidates** (§8). **Immediate high-stakes safety surfacing is allowed** — it may be surfaced immediately as a user-facing warning — but that surfacing **is not admission, not memory, not authority, and creates no ordinary cognition eligibility.** This reconciles Cluster-4-style immediate surfacing with Document B staging discipline. *(This is the single normative statement of the rule; §8 cross-references it.)*

`[OBLIGATION]` **Anti-agreeableness guard (the "Best-Self → Envelope Audit" rename lesson).** Envelope Audit measures a response/candidate against the **Track-A truthfulness envelope**, never toward an agreeableness or caution gradient. Self-audit must not install a covert "be more agreeable / more cautious" pattern. This is a first-class obligation, not a footnote.

## 8. Staging dispositions

`[OPERATOR-RATIFIED]` Staging is **permitted inside the chamber without an admission authority crossing**; the **crossing is gated** (Document A). Per-mode default staging dispositions — requirement-level only; **all admission still belongs to Document A**:

```
proposed insight / synthesis        → staged candidate; if later admitted, default ceiling = released / low-authority
contradiction / unresolved question → operator-visible or governance-visible candidate by default
risk flag / Envelope Audit concern  → operator-visible-only by default (immediate high-stakes surfacing per B-O6.1)
identity / seed / canon-affecting reflection → stricter than ordinary proposed-write; never auto-admit
```

`[DISTINCTION]` A staging disposition is the interior's *default routing intent for a candidate*; it is **not** an admission decision, an authority grant, or a projection. The admission ceiling and the crossing remain Document A §8.

`[OPERATOR-RATIFIED]` **Identity/seed/canon class disposition (Q-a resolved).** *"Stricter; never auto-admit"* is sufficient for Document B v0.1. A dedicated identity/seed/canon-affecting crossing path routes to the **Seed-Governance Blueprint + later A/B reconciliation**; it is **not designed here.**

## 9. Silence-as-cognitive-action boundary

`[OPERATOR-RATIFIED]` Silence may be first-class, but **only as a non-reentry audit footprint.** If the chamber chooses not to surface or stage a synthesis, it **may** (not must — B-O10.1) leave an operator/governance-auditable trace such as *"synthesis withheld / not staged."*

`[OPERATOR-RATIFIED] B-O10.1 — Footprint is permitted, not mandatory.` A withheld-synthesis footprint is **permitted, not required.** Mandatory footprints would risk forcing durability/recovery mechanics too early; whether and how a footprint persists is left to later governed/mechanics work.

`[OBLIGATION]` Any such footprint **must not feed retrieval, prompt assembly, persona, weights, identity, future runtime cognition, or ordinary memory. This document authorizes no reentry route; any future exception requires separate ratified doctrine and the applicable A/P4 boundary.** The footprint is observed by operators/governance; it is never read by the runtime to alter subsequent live behavior (Ledger §5 unifying property applied to absence).

`[DISTINCTION]` `withheld-synthesis footprint` records *that* the interior chose silence; it is not the withheld content re-entering by another door. The A-C3 / A-I1 tension (inspectability must not become re-entry) applies to absence exactly as to presence.
