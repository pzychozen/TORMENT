## 4. What Was Learned — Harness And Process Only

**Nothing below is about streams, vision, primitives, geometry, or memory. Every item is about our own apparatus.**

**Positive controls matter.** A baseline that fails tells you nothing unless you know it *could* have succeeded. Without
a positive control, this line would have read a near-chance result as a hard task.

**Weak controls manufacture survivors.** The first control made the relation blatant in a way that did not require the
capability the target demanded — so a baseline could pass it and still be incapable. **A control that eases the tested
capability certifies nothing**, and that is the general rule the attempt produced.

**A repaired control can still fail to yield an interpretable gate.** The second control was repaired along exactly the
axis that had been wrong, and the run was still uninterpretable — this time on a different baseline. **Fixing the known
defect does not guarantee a usable instrument.**

**Baselines-first protected the project.** The order — baselines run first; the candidate never looked at unless they
fail — meant no Brainvision-style reading was ever run on a harness that could not be trusted. **That is the single most
valuable thing the attempt did**, and it worked by refusing to produce a result rather than by producing one.

**External review remained useful, and the pull followed us into the empirical work.** The run report tried to interpret
target-task scores after the control gate had failed — reasoning that the interpretation pointed *against* the candidate
and was therefore safe. It was caught in review. **The same pull that produced vocabulary in the documents produces
premature interpretation in the data**, and it arrives wearing the costume of conservatism. Comprehension did not
prevent it. The outside reader did.
