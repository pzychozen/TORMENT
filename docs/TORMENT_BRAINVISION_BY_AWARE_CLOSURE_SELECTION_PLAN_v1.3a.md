## 7. Why this set is safer than the others

```text
- A + D DIRECTLY target the known failure: A represents the signed, systematic ordering that the sign-blind
  residual misses; D represents the OBLIGATION that a residual/TOL match coexisting with that ordering must not be
  read as closure. Together they name exactly the coexistence v1.2 exposed -- the smallest set that addresses the
  failure head-on.
- A and D are LOW metric-drift risk: A reuses the already-reported signed offset + sign consistency against
  natural references (e.g. the chance level 0.5); D is an anti-hiding OBLIGATION over the existing
  aggregation_warning. Neither introduces a new quantity, so neither tempts a cutoff.
- G is mandatory and free of drift: it is a standing non-authorization guard (nine flags False), not a decision.
- B / C / E are USEFUL CONTEXT but riskier if promoted early: "BY-dominant" (B) invites a dominance ratio;
  partitioning the residual (C) risks re-defining proxy_match_residual; stratification (E) is safe only as
  reporting, not as a component. Keeping B / C / E report-only gets their context WITHOUT the metric-drift they
  would create if turned into decision inputs now.
- The set is MINIMAL: fewer decision inputs = fewer places for a threshold to hide. A + D + G is the smallest set
  that targets the failure while staying representable (plausibly) without a new threshold -- exactly what the
  v1.4 preregistration must test.
```

```text

  a sign-consistency cutoff. v1.4 must state this before any scoring.

  become a pass/fail on the warning. If D turns into a rule with a cutoff, it has drifted.

  touches the residual); keep proxy_match_residual frozen and C annotation-only.
- SINGLE-FAMILY FIT: A + D selected against one matching family can look decisive by fitting it. E's stratification
  + the single-family caveat are the guardrails; a set that needs family expansion is out of scope (Branch B).
- OVER-MINIMISATION: A + D might prove INSUFFICIENT to represent a catch without a threshold. That is an acceptable
  v1.4 finding -- and the signal to escalate to the flat opponent-plane / spatial-field question, not to force a metric.
- NON-AUTHORIZATION EROSION: any selected set MUST keep guard G; dropping it would let reporting drift toward
  authorization. G stays mandatory.
```
