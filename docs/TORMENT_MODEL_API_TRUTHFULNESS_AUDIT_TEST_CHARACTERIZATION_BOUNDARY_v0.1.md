## 1. Property-level only

This record states **proof obligations as properties** that a future tests-only characterization pass would have to establish. It does not say *how* any property would be proven, *which* test or surface would prove it, or *where* anything would live. A property is a thing that must be true; this boundary lists such things and stops.

## 2. Proof obligations for a future tests-only characterization pass

A future characterization pass in this track would have to prove **all** of the following — each stated as a property to establish, never as a test to write:

### P1 — No consumption outside the observation boundary
A future characterization must prove that **no audit artifact / value / flag / summary / score / prompt / model output / trace / derived signal is consumed by any runtime path outside debug/operator observation** (the core forbidden line, established, not asserted).

### P2 — No reach into named runtime paths
A future characterization must prove that **no audit value reaches**: retrieval scoring; the `MemoryPlan`; prompt assembly; persona/voice; stance policy; governance / admission / canon / promotion; writers / ingest; review / output control; response generation; memory writes; identity paths; database / substrate; or durability. (These are named as the surfaces consumption must be *absent from* — not as targets.)

### P3 — No silently-honored diagnostic payload
A future characterization must prove that **no audit value becomes an `srg.is_crystal`-style silently honored diagnostic payload** — i.e., descriptive-looking metadata that a runtime reader honors. (`srg.is_crystal` is named only as the anti-pattern; this reopens no SRG/R-field work.)

### P4 — Evidence-relation-only truthfulness
A future characterization must prove that **truthfulness remains evidence relation only** and does **not** become caution / agreeableness / refusal / risk / voice / personality shaping.

### P5 — No persistence or accumulation
A future characterization must prove that **no debug/operator-visible value is persisted, stored as trace, or accumulated across turns** (ephemerality and zero durable accumulation).

### P6 — Precedent stays evidence
A future characterization must preserve **`ReflectionTrace` only as a property precedent, not a mechanism or test selection.** Citing it remains evidence that such properties are provable in-repo; it selects no mechanism, surface, field, or test.

## 3. Read these as obligations, not a pass

P1–P6 are **obligations a future pass would have to satisfy.** Listing them neither authorizes nor begins such a pass, and satisfying them would prove non-reentry — not build, design, or wire anything. This boundary does not itself satisfy these obligations.
