## 3. The Two Traps, Named Before Comparing

The BY/chroma arc taught two failure modes. Both must be held in view while reading the candidates, because they are
mirror images and it is easy to escape one by walking into the other.

```text
TRAP 1 -- POSITIVE FORCING (the trap we just escaped).
  A design that must sort cases into "BY-dominant" vs "generic proxy" will sort them -- whatever is true. The
  separation is then a fact about the design, not about colour. v2.27/v2.28 exist because of this.

TRAP 2 -- THE NULL SINK (the trap on the other side).
  A design in which nothing can ever survive the nulls, artifacts, and confounds will report "nothing survived" --
  whatever is true. That is equally uninformative, and it is MORE seductive, because it looks conservative and it
  never makes a false claim. It just never makes a true one either.

A design that cannot manufacture a positive result, but also cannot ever admit one, is not rigorous. It is inert.
The honest target is one where BOTH outcomes are reachable and BOTH could be wrong.
```

## 5. Recommendation

```text
PRIMARY:  D -- NULL-FIRST ADVERSARIAL FIXTURE DESIGN
FALLBACK: B -- CROSS-FAMILY SYNTHETIC FALSIFICATION TARGET

REASON: the BY/chroma work showed that FORCING POSITIVE SEPARATION creates conceptual traps -- the separation ends up
being a property of the design rather than of the world. A null-first adversarial design inverts the burden: artifacts,
proxy effects, and unresolved outcomes are PRIMARY and fixed in advance, so any future positive structure has a harder
path and fewer ways to smuggle itself in. Crucially, D is the only candidate whose own expected outcome ("nothing
survives") can be contradicted by the work -- which makes it the only candidate that can be WRONG, and therefore the
only one that is research rather than scaffolding.

D IS RECOMMENDED ONLY WITH ITS GUARDRAIL. A null-first design that makes survival impossible by construction is the
mirror image of the trap it was built to escape (Section 3, TRAP 2). Any v2.34-or-later D slice must, BEFORE designing
any null family, state what survival would look like and show it is reachable. If it cannot, D must be refused and the
choice falls to B -- or, honestly, to E.

FALLBACK B is genuine but under-specified: "distinguishable only as unresolved reporting patterns" must be sharpened
into a stated FAILURE CONDITION before it is a target rather than a theme. If B cannot state what would count as its
own negative result, it is schema work in an empirical costume, and it should not be opened.

NOT RECOMMENDED: A (scaffolding -- the seventh layer v2.32 warned about). C is not recommended AS A REOPENING WITHOUT
A NEW IDEA about the roughness / continuity confound; if such an idea exists, C becomes serious quickly, because it is
the only axis where this programme has already produced a falsifiable negative result.

E REMAINS AVAILABLE AND HONEST at any point, including immediately.
```
