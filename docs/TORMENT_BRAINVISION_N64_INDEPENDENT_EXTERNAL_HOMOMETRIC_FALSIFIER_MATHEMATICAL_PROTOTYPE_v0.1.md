## 5. Complete autocorrelation proof

Indicator polynomial:

```text
P_S(x) = Σ_{s∈S} x^s      in   Z[x, x⁻¹] / (x^64 − 1)
```

By collision-freeness:

```text
P_A(x) = P_U(x) P_V(x)
P_B(x) = P_U(x) P_V(x⁻¹)
```

Therefore:

```text
P_A(x) P_A(x⁻¹)
  = P_U(x) P_U(x⁻¹) P_V(x) P_V(x⁻¹)

P_B(x) P_B(x⁻¹)
  = P_U(x) P_U(x⁻¹) P_V(x⁻¹) P_V(x)
```

The two products are identical, so

```text

```

where `r_S(k) = |S ∩ (S − k)|`. This is a full-vector proof, not a per-lag check. The common periodic
autocorrelation vector (index `k = 0 … 63`) is:
