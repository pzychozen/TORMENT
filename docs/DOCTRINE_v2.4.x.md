# TORMENT 2.4.x Doctrine Note

1. **Do not add system just to add system.** Activate what already exists before inventing new layers.

2. **Memory is the epistemic core.** The semantic memory space is the main truth / retrieval substrate. Improve memory selection before redesigning memory itself.

3. **Spirit return is special.** Do not flatten spirit return into generic retrieval. Preserve its warmth, symbolic interaction, return modes, and distinct diagnostics.

4. **Advisory logic must earn influence.** If a layer shapes retrieval or behavior, it must be testable, observable, and easy to disable. Dead advisory logic should become real only behind flags first.

5. **Provenance is a hard boundary.** Anything that writes back into memory from cognition, tools, or derived processes must carry real provenance through ingest. No provenance, no self-writing.

6. **Automatic is allowed before autonomous.** Bounded automatic behavior is good. Broad autonomous behavior is not. Prefer narrow, auditable, reversible actions over initiative for its own sake.

7. **MCP is a governed capability layer.** Tool access belongs behind Spine/policy rails. Having MCP support does not mean agents should freely act on their own.

8. **Retrieval quality beats feature sprawl.** The next major gain should come from better memory selection, lane shaping, and grounded context use — not from adding more conceptual machinery.

9. **Safe defaults, risky features gated.** Keep low-risk observability and hygiene live. Keep core-behavior changes behind flags. Keep self-writing features disabled until structurally safe.

10. **Validate behavior, not just syntax.** A passing syntax check is not enough. Query paths, write-back loops, weighting, and feedback must be behaviorally reviewed.

11. **Keep the weirdness, lose the fake-smart.** TORMENT should stay distinctive, symbolic, and structurally strange — but never decorative, misleading, or unstable.

12. **When in doubt, preserve system truth.** If a change makes the system look smarter but makes provenance, retrieval, or governance less clear, reject or gate it.
