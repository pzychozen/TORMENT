## 3. What is not authorized

The artifacts are **not runtime authority.** They may **not**:

- control or write memory, identity, canon, final output, user truth, or persistence;

- make provider calls or do endpoint / MCP / API / schema / database work;
- alter `AgentRunner` / Terrain B behavior or open a private-runtime / dream chamber.

No such behavior is implied, inherited, or pre-approved by the recovery arc.

identity, output, truth, or writes). Absent such a gate, the artifacts stay sealed research
evidence and nothing more. This note grants that gate to no one.
