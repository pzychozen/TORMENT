## §2 Purpose and method

**Question:** what concrete carrier *shapes* could satisfy the already-complete Document A Q1–Q7 requirement frames as a shared prerequisite root — without authorizing any downstream lane?

**Method:** five candidate carrier-shape families (§4) are compared at requirement level against: the Q1 carrier-property set; the Q2 crossing-record obligations; the Q3 floor-binding obligations; the Q4/Q5/Q6 relation-exposure obligations; and the pre-carrier representation constraints envelope (P-1…P-9 required properties, A-1…A-8 anti-properties). The comparison labels are descriptive: SATISFIES / CANNOT / PARTIAL-with-named-gap. No weights, no total score, no ranking, no winner. F5 (the null/minimal carrier) is included as the falsification baseline: if existing evidence satisfies Q1 without a carrier, the carrier question ends.

All inputs were read read-only from the committed tree at `9f61cd2`. Precedent artifacts are cited as *evidence of shape feasibility only*, never as targets. F1-F5 are a survey set, not a closed universe; omission is not rejection; any future selection frame may add or justify excluding additional family shapes.

## §3 Requirement extraction (input; pinned from the read-only extraction pass)

### §3.1 Q1 — carrier properties (the measuring stick)

Doctrine carried verbatim: *"Presence of a reusable local `eid` is insufficient."*

- **Q1-1 Source-stability / eid-independence** — a reference must denote the same source independent of the local `eid` slot (serves P4 O1/O2). Forbidden reading: does not authorize adding a source-id field.
- **Q1-2 Reappend/reuse survivability** — same-source denotation survives `update_payload` canonical-last reappend and `eid` reuse (the "moving target behind an `eid`" problem). Forbidden: versioning/token/fingerprint by implication.
- **Q1-3 Same-source determinability** — same-source determination supported as a capability (P4 O1/O2; Gate B attributable writes). Forbidden: no comparison mechanism/hash/matcher selected; no threshold set.

- **Q1-5 Auditability / inspectability / recoverability** — operator/governance-auditable, recoverable-when-valid; never pinned/canonical by itself.
- **Q1-6 Non-authority / non-coercion** — carrying source evidence must not itself confer cognition-eligibility, projection, or authority (`diagnostic ≠ cognition-eligible`).
- **Q1-7 Operator-only-floor compatibility** — supports the floor; never provides an alternative admission path.
- **Q1-8 Containment compatibility** — no side-path into fan-out; separation structural, not tag-honoring (A-C2).
- **Q1-9 Determinism / stability of judgment** — identical inputs yield the same determination.
- **Q1-10 Carrier/substrate-agnosticism** — the property set holds for any carrier; the actual store routes to Stage-B.

## §4 Candidate carrier-shape family definitions (surveyed, not selected)

- **F1 — Source-identity reference layer.** A representation whose references denote *the same source* independent of the local `eid` slot, surviving `update_payload` reappend and `eid` reuse. Shape only: what a "stable source denotation" would have to be, not how it is computed or stored.
- **F2 — Append-only crossing ledger.** A durable, append-only record of admission crossings: occurrence, authority-provenance, pre/post containment state, contestability. Precedent shape (evidence only, not a target): the Track B `contest_events.jsonl` literal-replay ledger.
- **F3 — Quarantined candidate enclosure.** A structurally contained staging boundary holding candidate artifacts pre-admission, whose *only* exit is the governed admission crossing. Precedent evidence (inertness only, not a target): Layer 4 `CandidateShapedValue`.
- **F4 — Sidecar provenance annotation.** Lineage evidence carried beside existing rows in ordinary memory. Precedent shape (evidence only): ProvenanceV1 / `affect_attribution` stamping at the ingest merge seam.
- **F5 — Null/minimal carrier (falsification baseline).** No new durable carrier; same-source determination reconstructed from existing durable evidence (Spine envelopes, JSONL logs, existing provenance). Included so the survey has a null hypothesis: if F5 satisfies Q1, no carrier is needed.

## §9 F5 baseline analysis (the falsifiable core)

**Question:** does existing durable evidence satisfy Q1 without any carrier?

**Requirement-level analysis from source-known facts:** the live substrate exposes reusable local `eid` slots; `update_payload` performs canonical-last reappend, so the row behind an `eid` is a moving target; private/core and shared/relational stores are separate local-eid terrains, so local eid alone cannot be promoted into global source identity; existing provenance (ProvenanceV1 / `affect_attribution`) attributes *row and value lineage at write time* but does not denote *sources* stably across reappend/reuse. Consequently, at requirement level:

- **Q1-1:** partially reconstructable only where a source's rows were never reappended or reused — exactly the easy cases. Fails in general.
- **Q1-2:** fails: after canonical-last reappend plus `eid` reuse, no existing evidence deterministically re-binds a reference to its source; Q1's doctrine line ("presence of a reusable local `eid` is insufficient") states this terrain directly.
- **Q1-9:** not shown satisfied by F5 in this survey: reconstruction from existing logs/envelopes would require an already-selected completeness/replay-order convention, and none is selected here. This is a null-baseline limitation, not a new replay/determinism finding.

**Baseline verdict (requirement-level, descriptive):** F5, as currently evidenced, does **not** satisfy Q1-1/Q1-2 and has **not shown** Q1-9 satisfied; therefore the carrier question remains live. This is not a finding that a carrier is required, that any specific capability is needed, or that any family should be selected. Per the hardening constraint, this verdict justifies **only** the continued existence of the question. It does not select, prefer, or recommend any family, and it does not authorize building anything. If a future pass shows this analysis wrong (existing evidence suffices), the carrier question closes and HOLD stands.
