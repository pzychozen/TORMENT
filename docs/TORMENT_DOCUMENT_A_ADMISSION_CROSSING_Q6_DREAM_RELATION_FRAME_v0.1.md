## 3. Q6 boundary: staging-side relation, not Dream runtime

Each row below states **what the future crossing+carrier must support / require** so a future
Document-B-staged item can later relate to the governed admission crossing, the Document B obligation it
serves, and the reading that is **forbidden** (to keep it relation-level, not a runtime). Every obligation
