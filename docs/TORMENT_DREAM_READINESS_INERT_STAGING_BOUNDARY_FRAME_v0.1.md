candidate material* neither creates that material, opens a producer / store / chamber / runtime, nor

## 3. Boundary: inert material existence, not runtime

Each row states **a condition that inert staged candidate material must satisfy** (or must never violate) for
it to exist as inert, the boundary it preserves, and the reading that is **forbidden**. Every obligation is a
**property of the material**, never a chamber, producer, runtime, scheduler, store, or admission path. "Inert
staged material is admitted only by a governed Document A crossing" is a boundary on the material; it is
**not** an admission mechanism, producer, or runtime authorized here.
