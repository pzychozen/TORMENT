Line-ending handling during extraction:

The Markdown line terminator preceding the closing fence is excluded from the
canonical declaration bytes whether the checked-out representation uses LF or
CRLF.

For an LF representation:

  the final LF preceding the closing fence is excluded

For a CRLF representation:

  the complete CRLF pair preceding the closing fence is excluded

canonical declaration bytes.

The canonical declaration bytes must contain no CR byte.

invalid and must be rejected.

same canonical declaration must yield byte-identical canonical declaration
bytes and the same canonical_authorization_declaration_identity.

Markdown line terminator. It must not normalize arbitrary JSON string contents,
