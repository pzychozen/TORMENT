## G. Pause-Exit Prerequisites

Pause exit can be accepted only after all of the following conjunctive prerequisites are satisfied:

```text
1. formal pause record exists and has accepted identity;
2. controlling frozen governance identity is established, or its pending
   status is resolved in the single lawful form defined in Section C;
3. accepted preparation authority and mandatory disclosure identities are bound;
4. accepted GIT-1 design identity is bound;
5. lawful physical external-root path is supplied through a separate operator binding;
6. physical-root binding is independently reviewed and accepted;
7. exact root-creation act and exact preparation act are separately authorized;
8. exact operator and shell context are bound;
9. observation-channel requirements are incorporated;
10. directories-only scope is reproduced exactly;
11. fixed nineteen-directory order is reproduced exactly;
12. target, canonical input and governed runner remain non-contact;
13. Git and repository verification remain unauthorized during preparation;
14. no physical root or preparation directory already exists;
15. implementation remains unstarted and the implementation opportunity remains unconsumed;
16. independent review accepts the pause-exit package;
17. Hilmir provides explicit operator authorization for pause exit and the later preparation act.
```

All prerequisites are conjunctive.

No partial pause exit is allowed.

No implicit pause exit is allowed.

Elapsed time, operator intent, document completion, or design acceptance must not count as pause exit.

## H. Pause-Exit Authority

The pause-exit authority must be a separate accepted governance act.

It must:

```text
bind the exact formal pause record
bind every required prerequisite identity
bind the exact external-root path
bind the exact preparation-authority identity
bind the mandatory disclosure identity
bind the accepted GIT-1 design identity
bind the exact operator authorization

```

The default is:

```text
PAUSE EXIT LIMITED TO THE SINGLE TOOLLESS PREPARATION ACT
```

No broader-lane pause exit is authorized by this design.

Any pause exit extending beyond the single toolless preparation act requires
a separate accepted governance act and remains outside this boundary.

No authority beyond preparation may be inferred.

## I. Physical-Root Boundary

This design distinguishes these separate acts:

```text
external-root path proposal
external-root path binding
physical root creation
nineteen-directory preparation
activation re-observation
```

A proposed path is not a binding.

A binding is not creation authority.

Physical root creation requires its own separately accepted authority,
distinct from:

- the external-root path proposal;
- the physical-root binding;
- the pause-exit authority;
- the accepted preparation authority.

No accepted authority currently permits physical root creation.

Creation of the external root is not authority to create all nineteen directories unless the separately accepted preparation act says so.

Preparation does not authorize activation.

No physical external root or preparation directory is created by this design.
