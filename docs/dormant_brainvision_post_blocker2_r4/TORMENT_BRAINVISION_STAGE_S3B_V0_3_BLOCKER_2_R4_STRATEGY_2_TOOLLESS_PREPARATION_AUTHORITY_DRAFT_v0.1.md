Preparation creates directories only.

This draft does not create, simulate, or authorize creation of the external root or any of the nineteen directories.


No physical content may be created beyond the nineteen directories listed in Section F.

## H. Observation-Channel Constraint

The future preparation authority must reproduce and enforce the complete preparation observation-channel constraint without weakening, summarizing, generalizing, or replacing it:

```text
Preparation creates directories only.

No temporary, helper, staging, scratch, sidecar, transcript, observation,
redirected-output or log file is allowed.

No file-backed memory mapping is allowed.

Terminal output may be transcribed into the later preparation-record authoring act,
with transcription explicitly disclosed.

Human memory alone is insufficient.

Activation independently re-observes everything.

Activation observations govern.

No alternate non-file channel is authorized.
```

## J. Parent-Before-Child Creation Semantics

The future preparation act must preserve exact directory-order control.

Each listed parent directory must exist by direct creation in the fixed order before any listed child below that parent is created. Child-before-parent creation is not authorized.

The order in Section F is exhaustive and exclusive. No creation outside the authorized nineteen paths is permitted.
